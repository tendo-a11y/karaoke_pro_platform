# Karaoke Absolutis Bot

Полнофункциональный Telegram-бот для автоматизации заказов песен в караоке-клубах.

## ✨ Основные возможности

### 👑 Для администратора системы (Роль 1) - 100% готово
- **Управление клубами**: создание, блокировка, удаление, детальная информация
- **KJ операторы**: назначение, снятие, статистика работы, контакты, блокировка
- **Финансовая отчётность**: 
  - Отчёты за день/неделю/месяц
  - Сравнительный анализ по клубам
  - Расчёт комиссии 5% от выручки
  - Экспорт в CSV
- **Системные функции**: техподдержка, журнал действий, резервное копирование, мониторинг

### 🎵 Для KJ оператора (Роль 2) - 100% готово
- **Настройка клуба**:
  - Импорт базы песен из CSV (UTF-8, Windows-1251)
  - Управление услугами и ценами
  - Настройка столов (количество, режим нумерации)
  - VIP система (добавление, кешбек, уведомления)
  - Управление клиентами (поиск, баланс, статистика)
  - Бесплатные опции
  
- **Работа в течение вечера**:
  - Управление очередью по столам
  - Добавление заказов вручную
  - Перемещение заказов
  - Действия: выполнен ✅, удалить ❌, переместить ↕️
  - Закрытие стола с отчётом
  - Статистика вечера в реальном времени
  - Автоматический кешбек VIP клиентам

## 🚀 Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` файл:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id
DATABASE_PATH=karaoke.db
```

### Как получить данные:
- **BOT_TOKEN**: @BotFather → /newbot
- **ADMIN_ID**: @userinfobot → отправьте любое сообщение

## 💡 Примеры использования

### Импорт базы песен
Используйте файл `example_songs.csv` как шаблон:
```csv
artist,title,code
Imagine Dragons,Believer,ID001
The Beatles,Yesterday,BT002
```

### Работа с VIP
1. Добавьте VIP клиента по ID
2. Установите процент кешбека (например, 5%)
3. При выполнении заказа кешбек начисляется автоматически
4. Клиент получает уведомление о кешбеке

### Управление очередью
1. Выберите стол
2. Просмотрите очередь
3. Действия: ✅ Выполнен, ❌ Удалить, ↕️ Переместить
4. Закройте стол для получения отчёта
